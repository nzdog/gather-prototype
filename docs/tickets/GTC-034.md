# GTC-034 — Plan/Generate: Guided Builder L2 only shows options for first selected L1 option

**Type:** Bug
**Severity:** P2

## The Person
A host building their Christmas plan. They select both "Traditional roast" and "Seafood spread" at Level 1. They click Next. Level 2 shows only the Traditional roast sub-options. The seafood options are nowhere to be seen.

## The Fix
Added a `dependsOn` mechanism so L2 options are resolved dynamically based on all selected L1 options, merged and deduplicated.

## Evidence (Executor-Completed)

### What was built
Added a `dependsOn` config structure to `plan-option-tree-config.json` that maps each L1 option to its specific L2 options. Added a `resolveOptionGroups()` helper in `GuidedPlanBuilder.tsx` that, when a level has `dependsOn`, returns grouped options preserving L1 selection order — each group carries its parent L1 label. Options are deduplicated across groups. The render displays section labels (subtle uppercase text) and dividers between groups when multiple L1 options are selected. Falls back to a single unlabelled group when no `dependsOn` is present or no L1 selections exist.

Christmas mains L2 now has specific dishes for each style:
- Traditional roast → Glazed ham, Roast lamb, Roast chicken, Turkey, Beef brisket
- NZ summer BBQ → BBQ sausages, Steak, Chicken skewers, Lamb chops, Burger patties
- Seafood spread → Prawns, Smoked salmon, Oysters, Fish fillets, Crayfish
- Vegetarian / Vegan focus → Stuffed peppers, Vegetable Wellington, Mushroom risotto, Tofu stir-fry, Nut roast
- Mixed → representative selection from all styles

### Files changed
