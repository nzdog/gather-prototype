Root Cause
In src/app/api/events/[id]/generate/route.ts at line ~233, items are matched to teams via a filter on teamName:
const teamItems = aiResponse.items.filter(item => item.teamName === teamData.name);
If Claude returns team names in teams that don't exactly match the teamName values in items (a known AI consistency failure), the filter returns [] for every team. All items are silently dropped. A warning is logged but not surfaced. The route returns { success: true, teamsCreated: N, itemsCreated: 0 } and the frontend shows success regardless.
Same class of bug as [[GTC-024]], different code path.

Scope
Fix here:

src/lib/ai/prompts.ts — strengthen the plan generation prompt to explicitly instruct Claude to use identical team names in both the teams array and items array. Reference the [[GTC-024]] fix to SELECTIVE_REGENERATION_SYSTEM_PROMPT for the pattern to follow.
src/app/api/events/[id]/generate/route.ts — after the item creation loop, if itemsCreated === 0 and aiResponse.items.length > 0, return a 422 with a clear error (team name mismatch detected) rather than { success: true }. Surface the mismatch to the user.

Evidence (Executor-Completed)

Root cause confirmed
The initial plan generation route (`src/app/api/events/[id]/generate/route.ts`) filtered items per team using `aiResponse.items.filter(item => item.teamName === teamData.name)`. When Claude returned slightly variant team names in the items array (e.g. "Protein Team" vs "Proteins", "Side Dishes" vs "Sides"), every filter returned `[]`, all items were silently discarded, `itemsCreated` stayed at 0, and the route returned `{ success: true }`. The existing `console.warn` for unmatched items was only a log — it never blocked the success response or surfaced the error to the user. The `PLAN_GENERATION_SYSTEM_PROMPT` had only a weak format comment (`"teamName": "Team Name (must match a team name above)"`) that was insufficient to prevent Claude from varying team names.

Files changed
- `src/lib/ai/prompts.ts` — Added explicit `CRITICAL CONSISTENCY RULE — TEAM NAMES` block to `PLAN_GENERATION_SYSTEM_PROMPT` instructing Claude to copy team names character-for-character into items, and naming the consequence (item silently lost)
- `src/app/api/events/[id]/generate/route.ts` — After the item creation loop, added mismatch guard: if `itemsCreated === 0 && aiResponse.items.length > 0`, calls `findMissingTeamNames` and returns `{ status: 422 }` with the mismatched names instead of `{ success: true }`
- `tests/initial-plan-mismatch-test.ts` — New regression test (16 assertions across 4 suites)
- `package.json` — Added `test:initial-plan-mismatch` script
