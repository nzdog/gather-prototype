### Context

Hinge spec §8 + Moment 4 §10.2 (one derivation, two clocks — shared with E3's red-by-time line):
a maybe needs "time to decide," not "did you see this?" — no nudges. The clock is keyed to
**needed-by** (the item's drop-off time where one exists, else the event date), landing far
enough before needed-by for a reassignment to realistically work. **The exact constant is settled
at ticket time with Nigel's sign-off; real-event data will correct it** — this ticket must not
invent a default unilaterally. Near the decide-by, one follow-up in the same voice ("still good
for the pavlova? Kate needs to know by Thursday"). If it passes unanswered, the maybe goes red
through the standard door — the system out of moves. No new machinery beyond this.
