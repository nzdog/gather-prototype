# GTC-333 — the demo event name drift

**Status:** Open — a stub, filed 2026-09-27 at [[GTC-189]] slice 8's pin commit, on the founder's
instruction: the drift had no ticket. Not scoped.
**Severity:** proposed Medium — the `/demo` persona buttons fail against a fresh local seed.

---

### Signal

The demo event's name is a magic string compared in several places. `scripts/update-demo-dates.sql`
([[GTC-050]]) renamed the production demo event from `Henderson Family Christmas 2025` to `…2026`,
and the seed followed; the demo routes, the demo page copy and the tests did not. Recorded since
2026-07-09 in `.claude/skills/gather-run-and-operate/SKILL.md` §3, which says *"this needs a GTC
ticket"*; the six sites and the fix shape are in `.claude/skills/gather-config-and-flags` §7.

### What it breaks

- Against a fresh local seed, `GET /api/demo/tokens` returns no tokens and `POST /api/demo/session`
  cannot find the event.
- `npm run test:demo-ui` fails 1 of 4 — *"Participant API identifies demo event by known event
  name"* — and has since at least 2026-07-09. Recorded as a known failure in
  `GATHER-BUILD-CONSTANTS.md`, waiting on this ticket.

### Do not

Weaken the test to pass. The skill's instruction stands: reconcile the string everywhere — the
candidate is one shared constant, or `Event.isDemo` where the route already reads it.

Local check: `grep -rn "Henderson Family Christmas 202" src/ tests/ prisma/seed.ts`
