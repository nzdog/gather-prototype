# [[GTC-089]] — Remove "Confirm & Continue" button from GenerationReviewPanel — CLOSED

**Status:** Complete | **Branch:** master | **Commit:** [pending]

### What was found

- `onConfirmAndContinue` was a required prop on `GenerationReviewPanelProps`, passed from two call sites: the plan page (`handleReviewConfirmAndContinue`) and the demo review page (`handleConfirmAndContinue`).
- Both handler functions were only referenced as the value for this prop — no other callers. Both are safe to remove.
- The "Confirm & Continue" button was rendered alongside "Regen All" and "Regenerate Selected" in the panel's bottom action bar.

### What was changed

**`src/components/plan/GenerationReviewPanel.tsx`:**
- Removed `onConfirmAndContinue: () => void` from `GenerationReviewPanelProps` interface
- Removed `onConfirmAndContinue` from destructured props
- Removed `handleConfirmAndContinue` wrapper function
- Removed the "Confirm & Continue" button element

**`src/app/plan/[eventId]/page.tsx`:**
- Removed `onConfirmAndContinue={handleReviewConfirmAndContinue}` prop from `<GenerationReviewPanel>`
- Removed `handleReviewConfirmAndContinue` function (orphaned — only used as this prop)

**`src/app/demo/review/page.tsx`:**
- Removed `onConfirmAndContinue={handleConfirmAndContinue}` prop from `<GenerationReviewPanel>`
- Removed `handleConfirmAndContinue` function (orphaned — only used as this prop)
