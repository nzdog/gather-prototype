# [[GTC-132]] — Reconcile config keys and backfill missing matrix cells with templates — CLOSED

**Status:** Complete | **Branch:** feat/moment-one-redesign | **Commit:** 72c96ac

### What was found

1. **Key naming mismatch between component and JSON config.** `GuidedPlanBuilder.tsx` declared `ALL_CATEGORY_KEYS` using the short forms `sides` / `entree` / `snacks`, while `plan-option-tree-config.json` used the long forms `sides_salads` / `entree_starters` / `table_snacks`. Three keys, mechanical rename.

2. **The `'sides'` / `'entree'` / `'snacks'` literals appearing in `route.ts` files, `prompts.ts`, and `config-loader.ts` are NOT category-tree keys.** They are Moment-2 *section* names (the canonical output buckets `mains | sides | desserts | drinks | setup | dietary | other`). `config-loader.ts:59-66` already maps from long-form category keys to short-form section names (e.g. `sides_salads → 'sides'`). Confirmed by reading each consumer and not renamed.

3. **Matrix gaps wider than the original audit suggested.** The audit listed five categories with gaps; a thorough audit found that **55 of 140** (occasion × category) cells were missing — gaps in 11 of the 14 categories, including `other` which was missing from every occasion.

4. **Existing template duplication confirmed for non-food categories.** Byte-identical templates already ship across multiple occasions for `entree_starters` (5), `drinks_alcoholic` (8), `drinks_non_alcoholic` (10), `table_snacks` (8), `cleanup` (7), `furniture_equipment` (3), and `decorations` (5). This is the v1.5 acceptable state.

### Canonical templates

#### `entree_starters` — captured from existing 5-occasion duplicate (birthday_adult, wedding_reception, baby_shower, engagement_party, anniversary)

3-level template: Type → Preferences (with `dependsOn`) → Dietary. Includes Antipasto / Soup / Finger food canapés / Dips and breads / Salad entrée. Cascades into NZ-flavoured options (Rewena bread, NZ charcuterie, Marlborough wines).

#### `sides_salads` — picked from `wedding_reception` (most generic of the 4 authored)

3-level template using non-seasonal phrasing: Fresh salads / Roast vegetables / Grain and pulse salads / Seasonal sides / Mixed. Avoids occasion-specific terms like "Christmas summer" or "Easter autumn".

#### `drinks_alcoholic` — captured from existing 8-occasion duplicate (christmas et al.)

3-level template. Beer and cider / Wine / Spirits and cocktails / BYO / Mixed bar.

#### `drinks_non_alcoholic` — already universal (10/10), no backfill needed.

#### `table_snacks` — captured from existing 8-occasion duplicate

3-level template. Cheese and crackers / Dips and nibbles / Finger food / Charcuterie / Nuts and dried fruit.

#### `breakfast_brunch` — captured from `baby_shower` (only existing version)

3-level template. Classic cooked breakfast / Continental / Eggs and toast / Pastry and bakery / Smoothie and acai bowls. Content is brunch-focused, not baby-shower-specific, so reuse is acceptable.

#### `cleanup` — captured from existing 7-occasion duplicate

Single-level: Kitchen and dishes / Outdoor / BBQ area / Full venue tidy-up / Rubbish and recycling / All areas.

#### `furniture_equipment` — captured from existing 3-occasion duplicate

2-level template. Tables and chairs / BBQ and cooking equipment / Marquee / AV / Serving equipment, with cascade.

#### `decorations` — captured from existing 5-occasion duplicate

2-level template. Minimal / natural / Themed / DIY / Flowers and centrepieces / Professional styling, with cascade.

#### `activities_entertainment` — DISTILLED GENERIC (full content)

The 4 authored versions (kids' birthday, baby shower, engagement, anniversary) contain occasion-specific phrasing ("How well do you know the couple", "Engagement bingo", "Bouncy castle", "Decorate onesies", "Slideshow / memory display") that would land jarringly on christmas, adult birthday, BBQ, wedding, easter, or farewell. Picked any one as a template would break the appearance-of-breadth promise.

Distilled a single-level generic, free-text enabled, no `dependsOn` cascading:

```json
{
  "label": "Activities & Entertainment",
  "levels": [
    {
      "level": 1,
      "question": "What activities or entertainment would you like?",
      "options": [
        "Music or playlist",
        "Games or activities",
        "Photo or memory display",
        "Group conversation prompts",
        "Relaxed — no structured activities"
      ],
      "freeText": true,
      "freeTextPlaceholder": "Describe any activities or entertainment...",
      "breadcrumbLabel": "Activities"
    }
  ]
}
```

Each option is universally applicable: a christmas family lunch, an adult birthday party, a casual BBQ, a wedding reception, an easter family gathering, and a farewell could all plausibly opt into any of these.

#### `other` — NEW minimal template

No precedent in config. Designed minimal, free-text only, no options:

```json
{
  "label": "Other",
  "levels": [
    {
      "level": 1,
      "question": "What else would you like to plan?",
      "options": [],
      "freeText": true,
      "freeTextPlaceholder": "Describe anything else you'd like to include..."
    }
  ]
}
```

Schema-conformant — matches the `LevelConfig` interface in `GuidedPlanBuilder.tsx:36-44` (`options: string[]` with empty array, `freeText: true`, no `dependsOn`).

### Known limitations

- **`activities_entertainment` for `bbq_casual` and `farewell` shows generic options that don't land as naturally as occasion-specific options would.** A casual NZ BBQ might want "Yard games / cricket" rather than "Group conversation prompts"; a farewell might want "Speeches and tributes". The distilled generic ships per the v1.5 product call but is the most likely candidate for early authored replacement.

- **`breakfast_brunch` template uses baby_shower-derived options** (acai bowls, smoothie bar). Universally applicable but shoulders a slight afternoon-tea aesthetic. Acceptable for v1.5.

- **The diff line count looks alarming** (~5238 inserted, ~2307 deleted on the JSON file) but `git`'s line-alignment heuristic accounts for the deletions — Python deep-equal verification confirms zero existing-cell mutation. The 2,307 "deletions" are diff alignment artifacts where `}` lines reformat to `},` lines as new entries are inserted after them.

- **`defaultCategories` policy applied as specified.** Universal-opt-in does not mean universal-default. New cells exist in the categories map but were NOT added to any occasion's `defaultCategories`. The arrays remain byte-identical to pre-backfill.
