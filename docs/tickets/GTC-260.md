**Status:** Complete | **Branch:** `feat/moment-one-redesign` | **Commit:** `059f99b` | **Effort:** low

### The three states — founder ruling, 2026-08-29

`Event.askAuthorLine` holds **three** states, and the difference between the first two is
load-bearing:

| stored | means | composes to |
|---|---|---|
| `NULL` | never authored | the generated draft — today's behaviour, unchanged |
| `''` | **deliberately no line from the host** | the bare greeting, `Hi Rob,` — and **not** the draft |
| a value | her words | `Hi Rob - <value>` |

All three ride one expression. `composeAsk` reads
`storedAuthorLine ?? draftAuthorLine(event)`, and `??` catches `null` but not `''` — so the
fall-through happens for state 1 and not for state 2, with no branching added anywhere.
`authorLineFor` already handled state 2: `written ? \`Hi ${name} - ${written}\` : \`Hi ${name},\``.

**Rationale, recorded:** `authorLineFor`'s own comment already treats the blank case as
deliberate — movement 1 is *"hers to cut to nothing"* — and Hinge §5 makes the **handover** the
load-bearing beat, not movement 1's length. A host sending to sixty people, or re-sending after
she has already said her piece, should be able to decline to speak without Gather's words
standing in for hers. The branch existed before there was a way to reach it; the ruling gave it
the way in rather than changing what it does.

### ⚠ SUPERSEDES the normalise-empty-to-NULL rule approved earlier the same day

That rule — write site collapses `''` to `NULL` — is **superseded, not deleted**. It is marked
as such with its reasoning in `prisma/schema.prisma` and in [[GTC-259]].

Its premise was that a stored `''` suppresses the draft. That is true and was measured (see
[[GTC-259]]'s correction section — the first description of the mechanism, "composes an empty
movement 1", was wrong; `authorLineFor` guards the blank case and all three movements survive).
The suppression turned out to be the **feature**.

**What normalisation survives:** whitespace-only normalises to `''`, **not** to `NULL` —
`authorLineFor` trims before deciding, so `'   '` composes identically to `''` and storing it
verbatim would be a fourth spelling of the third state. Values are stored trimmed. The column
holds exactly `NULL`, `''`, or a trimmed non-empty string, and nothing else.

### The UI — what was chosen, and why

The ruling requires *"put the draft back"* and *"send without a line from me"* to be separate
and legibly different. Both empty the box and they mean opposite things, so the box itself
cannot carry the distinction.

**Chosen: two plainly-labelled buttons and a status line that names the current state.** The
simplest thing that reads clearly — no mode switch, no radio group, no confirm dialog.

| Control | Writes | Effect |
|---|---|---|
| **Save my line** | the trimmed textarea | state 3 (or state 2, if she emptied the box first) |
| **Put the draft back** | `NULL` | state 1 — the draft returns to the box |
| **Send without a line from me** | `''` | state 2 — the box empties and stays empty |

Labelled as the **sentence**, not the state: "Clear" would be exactly the ambiguity the ruling
forbids, and "Set to null" is not a thing a host says. Each is disabled when it is already
true, so the enabled set is itself a readout of where she is.

The status line says which of the three is current, because an empty box and a box full of the
draft look nothing alike but read the same if nothing says so:

- state 1 — *"This is the draft, in your voice. Save it to make it yours, or send without a line from you."*
- state 2 — *"No line from you. Guests get the greeting and then the handover — the preview below is exactly what they will read."*
- state 3 — *"Saved. Everyone gets this line, including anyone you add later."*

State 2's copy points at the preview rather than quoting the greeting, so what she reads is the
composed message itself — Hinge §1's rule for this screen, not a description of it.

### Live round-trip — the real route, real auth, the real event

`BASE_URL=… npx tsx scripts/verify-gtc260-live-roundtrip.ts` against the dev server, on
**Henderson Family Christmas 2026** (`cmsdv856300181yqrwbne7pbw`, CONFIRMING, 42 recipients) —
the event [[GTC-187]]'s evidence was measured on. **34 passed, 0 failed.**

Henderson carries no `EventRole`, so no session can pass `requireEventRole` on it. The script
creates a temporary User + Session + EventRole, and deletes all three in `finally` along with
restoring `askAuthorLine` — then asserts the restoration, so a dirty fixture fails the run.

**The three states, printed side by side by the run itself:**

```
  state 1  null   → Hi Rob - We're doing Henderson Family Christmas 2026 on Thursday, 24 December,…
  state 2  ''     → Hi Rob,
  state 3  value  → Hi Rob - Second thoughts - come hungry.
```

What it proves, in order:

- `GET` and `PATCH` without a session are both **401** — auth is real, not assumed.
- Starts `null`; composition falls through to the draft.
- **Write → reload → confirm:** `PATCH` stores the line, the column holds it, a fresh `GET`
  returns it, and movement 1 composes as *her* line rather than the draft.
- Surrounding whitespace is trimmed off the stored value.
- **Overwrite, not version:** a second `PATCH` replaces the first, no prior value survives.
- **State 2:** `PATCH ''` returns `''` **and not null** — the assertion is worded against the
  superseded rule on purpose, so a regression to it fails loudly. The **column** holds `''` and
  is not NULL; a fresh `GET` returns `''`; composition gives `Hi Rob,` and does **not** contain
  the draft.
- **State 1:** `PATCH null` returns null, the column is NULL, and composition contains the draft.
- **The difference, proven not assumed:** NULL and `''` are asserted to be different *stored
  values* and different *composed messages*, and all three states to be mutually distinct.
- The **handover survives in all three** — §5's load-bearing beat is never the one cut.
- Whitespace-only stores `''` — state 2, not state 1.
- A non-string body and a missing key are both **400**, and neither changed the column — a
  silent no-op here would be the GTC-151 failure shape.
