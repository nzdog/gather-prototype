# GTC-085 — Import Contacts: Per-Platform Accordion Help Section — CLOSED
**Status:** Complete | **Branch:** master | **Commit:** 3883944

### What was found
The Import Contacts modal help section was a single collapsible accordion
(`helpOpen` state) with the trigger text "Need help exporting your contacts?".
Expanding it revealed all four platform entries (iPhone, Android, Gmail,
Outlook) at once in a `<ul>`. Users had to scroll through all four even if
only one was relevant.

### What was changed
`src/components/plan/ImportCSVModal.tsx`:

1. Replaced the single `helpOpen` `useState(false)` with four independent
   state variables: `iPhoneHelpOpen`, `androidHelpOpen`, `gmailHelpOpen`,
   `outlookHelpOpen`.
2. Changed the outer trigger "Need help exporting your contacts?" to a
   static `<p>` heading "How to Import your Contacts" — no button, no
   chevron, no onClick, no aria-expanded. Purely presentational.
3. Removed the outer `<ul>` wrapper and the single outer accordion.
4. Added four individual accordion items, each:
   - Native `<button type="button">` trigger with `aria-expanded`
     reflecting its own state and `aria-controls` pointing at its own
     content id (`import-help-iphone`, `import-help-android`,
     `import-help-gmail`, `import-help-outlook`).
   - Trigger label is the platform name only: `iPhone`, `Android`,
     `Gmail / Google Contacts`, `Outlook`.
   - Chevron: `ChevronRight` when closed, `ChevronDown` when open
     (matching existing lucide-react pattern from GTC-084).
   - Default state closed. Each manages its own open/closed state
     independently — opening one does not close another.
   - Instruction text (copy) unchanged from GTC-083.
   - Guide link URLs unchanged from GTC-083.
   - Button-style class on guide links unchanged from GTC-084
     (`inline-block mt-2 px-4 py-2 bg-gray-200 text-gray-700 rounded-md hover:bg-gray-300`).
   - `target="_blank" rel="noopener noreferrer"` preserved.
5. Updated `resetModal()` to reset all four new state variables instead
   of the removed `helpOpen`.

### Known limitations
None.
