# [[GTC-077]] — Remove Gather Templates tab from Past Events page — CLOSED

**Status:** Complete
**Branch:** gtc-042-part1-nudge-schema
**Commit:** 500d426

### What was found
- `GET /api/templates/gather` was only called from `TemplateList.tsx` — nowhere else in `src/`
- The Gather Templates tab was always empty (0 seeded templates) — misleading UI
- The tab switcher, `gatherTemplates` state, `activeTab` state, and the inline Gather-templates-as-empty-state fallback from [[GTC-076]] were all unnecessary complexity
- `CloneTemplateModal` import in templates page was only used for Gather templates — no longer needed
- The `GET /api/templates/gather` endpoint itself is retained for future use

### What was changed

**`src/components/templates/TemplateList.tsx`**
- Removed `gatherTemplates` state, `activeTab` state, and Gather API fetch
- Removed tab switcher UI entirely
- Removed Gather-templates-inline empty state fallback
- Simplified to a single list of host past events
- Empty state: "Your past events will appear here once your first event completes."

**`src/app/plan/templates/page.tsx`**
- Removed `CloneTemplateModal` import and all related state (`cloneModalOpen`, `selectedTemplateId`, `handleClone`, `handleCloneComplete`)
- `onClone` now points to `handleUseAgain` (all templates use the direct flow)
- Removed CloneTemplateModal render block

### Known limitations / follow-up flags
- `GET /api/templates/gather` endpoint retained — not removed per ticket scope
- `CloneTemplateModal` component file retained — may be needed if Gather templates are reintroduced

- [x] No Gather Templates tab visible

- [x] Empty state reads "Your past events will appear here once your first event completes."
- [x] Host past events display correctly when they exist
