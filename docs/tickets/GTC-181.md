# GTC-181 — E4: Bounce detection

**Status:** Open | **Branch:** TBD | **Commit:** [pending] | **Effort:** medium

*Effort level is a proposal from the discovery-report ticket breakdown — run `/effort` manually
before execution.*

### Context

Hinge spec §7: bounces are red on arrival — a bounce is not a silence, it's a dead channel;
nudging it sends more messages into the same void. The system is out of moves immediately, so the
ask goes red at once, transparently.

Moment 4 spec §10.9 is explicit that this is **a build instruction, not a ruling**: "Its ticket's
first task: investigate TNZ delivery-receipt capability. If webhooks exist, wire them. **If the
carrier cannot report delivery, the principle degrades gracefully**: an invisible bounce is
indistinguishable from silence, travels the nudge path, and reaches Kate at exhaustion or her time
line — later than specified, but nothing lost. The fallback is documented in the ticket, never
silently substituted for the target."

Today: zero bounce-handling code anywhere. No delivery-status webhook receiver on either the TNZ
client (`tnz-client.ts`) or the Twilio client (`twilio-client.ts`). `send-sms.ts` only
distinguishes `SMS_DISABLED`/`INVALID_NUMBER`/`OPTED_OUT`/`SEND_FAILED` (a failed API call at send
time) — not a carrier-reported bounce after successful submission.

### Scope

**Fix here (in order, per §10.9):**
1. Investigate TNZ's delivery-receipt/webhook capability (and Twilio's, secondarily). Document
   findings in this ticket's Evidence section regardless of outcome.
2. If webhooks exist: wire a receiver, mark the ask red-on-arrival immediately on bounce.
3. If webhooks don't exist: implement and **clearly document** the graceful-degradation fallback
   (bounce travels the ordinary nudge path per E1, reaches Kate at exhaustion or the E3 red-by-time
   line). Do not silently ship the fallback as if it were the target behavior — the gap must be
   visible to whoever reads this ticket closed.

**Do not touch:**
- All Do-Not-Touch Zones in `GATHER-BUILD-CONSTANTS.md`.
- The general nudge path itself beyond what the fallback requires.
