## Why

The founder ruled on 15 Nov 2026 for "a simple daily count, no
cookies or addresses" (GTC-464 ruling 1 left it for its own ticket).
Gather did not know how many people reach its front pages or where
they come from. This ticket writes one plain line to the server log
for each real visit to three pages, and changes the privacy page in
the same commit, so the page and the code agree from the first
deploy.

## The line

    [page-visit] <page> <source>[ tag=<label>]

- page: home, demo or new, from the code, never from the request.
- source: the main name of the website the browser reports
  (facebook.com, instagram.com, google.com, nzherald.co.nz);
  "internal" for Gather's own site and for a move inside it;
  "direct" when no Referer comes; "other" when what comes is not a
  usable website name.
- tag: on home and /demo only, utm_source lowercased, when it is one
  of facebook, instagram, email, flyer, podcast, magazine.

Read from the request: the Referer, the Host, the browser's own
fetch headers (Sec-Fetch-Dest, Sec-Fetch-Mode, Sec-Fetch-Site), the
purpose headers (Sec-Purpose, Purpose, X-Purpose) and Next's
prefetch header, and nothing else. Never the user agent, a cookie or
an internet address. From the query, utm_source only.

## What counts

- A real page load: Sec-Fetch-Dest document and Sec-Fetch-Mode
  navigate.
- A move inside the site (Next fetching the next page for a click):
  Sec-Fetch-Dest empty and Sec-Fetch-Site same-origin, written as
  "internal" (Q4, kept only because the production-build proof
  passed).
- Never: a prefetch or background preview (a purpose header naming
  prefetch, prerender or preview; Next-Router-Prefetch), or a request
  without the browser's fetch headers (link-preview fetchers,
  monitors, HEAD requests, curl).
- A reload counts again: these are page loads, not people.

## Cleaning the Referer

The header comes from outside and is treated as hostile. Blank is
"direct". Over 2,000 characters, anything but printable ASCII,
unreadable as a web address, not http or https (but four named
Android apps), an IP address, a one-word or private host name
(.local, .lan, .internal, .localhost, .home.arpa), any character
outside a-z, 0-9, dot and hyphen, or over 64 characters after
cutting: "other". Only the host is kept, cut to its main name (a
short list of two-part endings such as co.nz keeps three parts),
with the Facebook, Instagram, Google and X names merged ("is, or
ends with .facebook.com", never "contains"). The finished line must
match one whole-line pattern or nothing is printed, so no line can
carry a newline, a space or a "[" from outside, and none can pose as
a [demo-tally] line.

## The cap

At most 120 lines a minute from one server. A minute after one with
drops starts with one `[page-visit-cap] dropped N` line.
