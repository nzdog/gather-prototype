# GTC-427 - Three moving checks fixed (Batch 3, Part 0)

> Filed by Claude Code on 30 Oct 2026, from the founder's Batch 3 prompt.
> Branch feat/tweaks-emails from origin/main at 541cd44. Part 0 of
> Batch 3; Part 1 is [[GTC-428]], the designed guest emails.

## Why

The first Batch 3 run (30 Oct 2026, the same day) stopped at its
starting checks: test:tweaks-d, test:tweaks-h and test:tweaks-i were
each red on one check, U5, on main itself (541cd44), before anything was
changed.

U5 asked two things: that neither untracked script
(scripts/dev-login.ts, scripts/print-host-link.ts) was in any commit
from the suite's base to HEAD, and that nothing under src/app/api,
src/lib or prisma changed from the base to HEAD. HEAD moves with every
commit, so any later work in those folders turns it red. Two of the
morning's merges did:

```
f45ae01 fix(GTC-425): the demo's copy-start route answers 404 ...
        src/app/api/demo/session/route.ts, src/lib/demo/start-switch.ts
a5824bd feat(GTC-426): Person.sampleEventId ...
        prisma/schema.prisma and its one migration
```

The condition is the same expression: the same paths, the same empty
result, the same two scripts. Only the end of the range is fixed. A
fixed commit git cannot read makes `git diff` fail, and
`zones.status === 0` then turns U5 red, so a wrong hash cannot pass.
