# GTC-146 — Single-call architecture brought to feat/moment-one-redesign — CLOSED

**Status:** Complete | **Branch:** feat/moment-one-redesign | **Commits:** `e250f64` (cherry-pick), `be66454` (cleanup)

This ticket merges the experimental single-call AI generation pattern from
`experiment/single-ai-call` (GTC-145, `a27f781`) onto
`feat/moment-one-redesign` as the canonical Moment 2 generation pattern, and
removes the deprecated per-section infrastructure that the experiment had
left in place (deprecated-by-comment) for back-compat.

## What was found

The experiment branch (`experiment/single-ai-call`) had proven the
architectural choice — single-call replaces per-section — and the verification
on a 17-person Christmas event produced a 25-item plan in ~44s with no
cross-section duplication. But the experiment had left the per-section
infrastructure in place behind `DEPRECATED` comments, leaving two architectures
in the codebase with one labelled "deprecated." This ticket lands the
single-call as canonical and removes the deprecated infrastructure outright.

The two-commit structure was chosen deliberately:
1. **Cherry-pick** preserves the experimental work as a recognisable commit
   in the history of `feat/moment-one-redesign`.
2. **Cleanup** is a logically separate change (removing dead code is not the
   same change as introducing the new architecture), so it gets its own
   commit with its own message.

## Phase 2 cleanup

A separate commit on top of the cherry-pick, removing dead code that the
experiment had left deprecated-by-comment.

**`src/lib/ai/prompts.ts`:**
- `buildSectionPrompt` (per-section food generation, including its DEPRECATED
  dietary branch from GTC-137)
- `buildGapPrompt` (per-section gap-fill)
- `buildDietaryCoveragePrompt` (replaced by single-call's bundled
  `dietaryCoverage` field in the JSON response)
- `buildThingsToConsiderPrompt` (replaced by single-call's bundled
  `thingsToConsider` field)
- Dead support: local `flattenSelections` helper, `MOMENT2_SECTION_LABELS`
  table, `SECTION_KEY_TO_FAMILY` table
- Dead types: `Moment2Section`, `VALID_MOMENT2_SECTIONS`,
  `Moment2GeneratedItem`, `Moment2HouseholdData`,
  `Moment2SectionHouseholdData`, `Moment2SectionInput`
- Removed unused `getSectionReferenceItems` import (still imported separately
  by `finalize-plan/route.ts` from `config-loader`)

Kept in `prompts.ts`: `buildPlanGenerationPrompt`, its input types
(`PlanGenerationCategoryInput`, `PlanGenerationInput`), the shared
`OptionTreeLevelSelection` and `OptionTreeSelections` types (used by
finalize-plan), and the entire legacy v1 surface
(`PLAN_GENERATION_SYSTEM_PROMPT`, `PLAN_REGENERATION_SYSTEM_PROMPT`,
`EXPLANATION_SYSTEM_PROMPT`, `SELECTIVE_REGENERATION_SYSTEM_PROMPT`,
`buildGenerationPrompt`, `buildRegenerationPrompt`, `buildExplanationPrompt`,
`buildSelectiveRegenerationPrompt`) which is still imported by `generate.ts`.

**`src/lib/ai/token-limits.ts`:**
- Removed `MAX_TOKENS_SECTION_GENERATION`, `MAX_TOKENS_GAP_FILL`,
  `MAX_TOKENS_DIETARY_COVERAGE`, `MAX_TOKENS_CONSIDERATIONS`
- Tightened the file-level docstring to reflect that `MAX_TOKENS_FULL_PLAN`
  is now the only Moment 2 cap

**`src/app/api/events/[id]/generate-section/route.ts`:** entire file deleted.
The 410-Gone stub from the experiment is no longer useful — the route
shouldn't exist at all. Empty parent directory removed.

## Known limitations

- **`EventSetup.generatedData` column kept** (deprecate-by-disuse). The
  column is no longer written by the single-call finalize-plan route. A
  migration to drop it is a separate hygiene ticket; rolling it into GTC-146
  would have added migration risk to a code-only refactor.
- **Legacy `/api/events/[id]/generate` route untouched.** It uses
  `generate.ts` (the v1 GuidedPlanBuilder path) and is not on the Moment 2
  flow. Out of scope for this ticket.
- **Single-response error surface area is larger than per-section.** Inherited
  from the experiment. Production scale may need retry logic on the single
  call. Surfaced by GTC-142's `callSiteLabel` truncation logs if it bites.
- **16K token cap may be insufficient at 50+ guest scale.** Inherited from
  the experiment. Will surface via the same truncation logs.
- **`console.error` in regenerate routes** is unchanged (out of scope).
