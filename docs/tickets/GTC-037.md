# GTC-037 — Plan/Generate: Guided Builder team names don't match selected categories

**Type:** Bug
**Severity:** P2

## Problem

When a host selects specific categories in the Guided Builder (e.g. Mains, Seafood spread, Dessert, Drinks), the generated plan renames them to generic AI-invented names like "Proteins & Mains", "Desserts & Sweet Table", "Drinks & Beverages". The connection between what the host configured and what was generated is broken.

## Root Cause

`compileGuidedPrompt` compiled category selections into a host description but never explicitly instructed the AI to use those category labels as team names. The AI was free to invent its own team names, making the guided builder feel pointless.

## Fix

1. **`src/lib/ai/generate.ts`** — `compileGuidedPrompt`: Added a `TEAM NAMES INSTRUCTION` line at the end of the compiled prompt listing the selected category labels in order, with explicit instructions not to rename, merge, or reorder.

2. **`src/lib/ai/prompts.ts`** — `PLAN_GENERATION_SYSTEM_PROMPT`: Added a `HOST-PROVIDED TEAM NAMES` section reinforcing that when the host description includes a team names instruction, the AI must use those exact names. Same pattern as the GTC-024 fix to `SELECTIVE_REGENERATION_SYSTEM_PROMPT`.
