# GTC-039 — Plan/Items: Category order, unwanted AI categories, and PDF download

**Type:** UX / Bug
**Severity:** P2

## The Fix

### 1. Category order matches Overview screen
- Set `displayOrder` on Team records when AI creates them (1-based index matching AI response order)
- Items API now returns `team.displayOrder`
- Items & Quantities accordion sorts by `displayOrder` when any team has a non-zero value (guided build)
- Falls back to alphabetical when all teams have `displayOrder: 0` (quick generate / manual)

### 2. AI only generates for selected categories
- Added `CATEGORY RESTRICTION` instruction to the guided prompt (both client-side `compilePromptInline` and server-side `compileGuidedPrompt`)
- Also added the `TEAM NAMES INSTRUCTION` to the client-side `compilePromptInline` (was only in server-side copy)
- Instruction tells AI to generate items ONLY for listed teams, omitting any extras (e.g. setup, equipment, cleanup)

### 3. PDF download
- "Download PDF" button in Items & Quantities modal header (visible when items exist)
- Opens a print-friendly page in a new window with browser print dialog
- Includes: event name, date, categories as section headers, items with quantity, assigned person, confirmation status
- Black and white friendly, clean layout
