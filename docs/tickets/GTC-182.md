# GTC-182 — E5: Remove host-facing seen status; add nudge-clock display

**Status:** Open | **Branch:** TBD | **Commit:** [pending] (filed `e5f6e82`) | **Effort:** medium

*Effort level is a proposal from the discovery-report ticket breakdown — run `/effort` manually
before execution.*

### Context

Hinge spec §6: "Seen" is refused, with its reason — seen-without-response starts stories in her
head, which may or may not be true, and all of which she then carries. Seen-status doesn't inform;
it manufactures wondering at higher resolution. **What replaces it: the nudge-clock.** Each yellow
box quietly shows what the system will do next and when (*nudge in 2 days*) — information about
the system, not about the guest.

Today: `AccessToken.openedAt` is explicitly rendered to the host — `InviteStatusSection.tsx`'s
"Opened" stat tile, `PersonInviteDetailModal.tsx`'s "Link opened" timeline row — a direct,
host-visible seen-without-response indicator, exactly the pattern the spec refuses.

### Scope

**Fix here:**
- Remove the "Opened" stat tile from `InviteStatusSection.tsx` and the "Link opened" timeline row
  from `PersonInviteDetailModal.tsx`.
- Add a nudge-clock computed field (next scheduled nudge + when, from E1's rebuilt cadence data)
  and surface it in the same locations those elements are removed from.

**Do not touch:**
- All Do-Not-Touch Zones in `GATHER-BUILD-CONSTANTS.md`.
- `AccessToken.openedAt` itself, or the system's own use of it — the spec objects to *surfacing*
  it to the host, not to the system knowing it. Do not delete the underlying data capture.

### Dependencies

E1 (GTC-178) — the nudge-clock needs the rebuilt day-4/day-7 cadence data to compute against.

### Acceptance

- [ ] No host-facing UI shows "opened"/"seen" status anywhere in the invite-status surfaces.
- [ ] A nudge-clock ("nudge in N days") renders in the same locations, computed from E1's cadence.
- [ ] `npx tsc --noEmit` clean, build passes.
- [ ] Browser walk: confirm the removed elements are gone and the nudge-clock renders correctly
      for a yellow (system's-on-it) box.
