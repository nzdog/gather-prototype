# [[GTC-102]] — Opening screen: the arc and the entry point — CLOSED

**Status:** Complete | **Branch:** feat/moment-one-redesign | **Commit:** b460f68

### What was found

- The plan page (`src/app/plan/[eventId]/page.tsx`) already imported `useSearchParams` and had a `useEffect` (lines 418-426) that detected `?setup=true`, opened the Edit Event modal, and stripped the param via `router.replace`.
- Primary button style in the codebase is `bg-accent text-white hover:bg-accent-dark` using the sage green palette defined in `tailwind.config.js`.
- No existing `MomentArc` or `SetupOpeningScreen` components existed.

### What was changed

**New files:**
- `src/components/plan/MomentArc.tsx` — Reusable four-moment arc indicator. Accepts `currentMoment: 1 | 2 | 3 | 4`. Renders the four fixed labels with the current moment visually highlighted (full opacity, accent circle, bold text) and others subordinate (reduced opacity, grey circle).
- `src/components/plan/SetupOpeningScreen.tsx` — Full-screen opening experience. White background, centered content (max 600px). Displays the opening line, the MomentArc (moment 1 highlighted), and the "Ready to start herding →" entry button. Fades out on click before calling `onStart`.

**Modified files:**
- `src/app/plan/[eventId]/page.tsx`:
  - Added import for `SetupOpeningScreen`
  - Added `showSetup` state, initialised from `searchParams.get('setup') === 'true'`
  - Replaced the old `?setup=true` useEffect (which opened Edit Event modal) with one that only cleans the URL param
  - Added early return rendering `SetupOpeningScreen` when `showSetup` is true, before the normal dashboard

### Known limitations

- The fade-out transitions to the normal plan page (not yet to a Moment 1 input view — that is [[GTC-103]]'s scope).
- The old post-payment flow that auto-opened the Edit Event modal is replaced by the opening screen. The Edit Event modal is still accessible from the normal dashboard.
