# GTC-297 — The host's one-off link

**Status:** Open — filed from the founder rulings of 2026-09-14, not started, **not scoped** |
**Branch:** TBD
**Severity:** not set at filing — the founder's to set.

**Filed on the founder's instruction**, from ruling N in [[GTC-189]] (*Founder rulings — third
pass*). This ticket records the ruling and what it meets. It proposes no shape.

> THE HOST GETS A ONE-OFF LINK that answers only the carried item. Narrow by construction. Record
> that this is the single exception to Ruling 8 and that widening it is widening a ruling.

---

### The case it serves — [[GTC-189]] ruling A2

The host is another household's explicitly picked contact (`Household.contactPersonEventId`), and
that household has a child who holds an item. The child's ask is carried to the host. It is the
only case in the model where the host receives an ask, and this link is how the host answers it.

### ⚠ 2026-09-15 — this ticket now pairs with [[GTC-308]]

[[GTC-189]] ruling AB (fourth pass) answered decision 20: the host-as-carrier message is **Gather's
voice only**, movements 1 and 2 skipped, *"she is not introducing herself to herself."* That message
is [[GTC-308]]'s and this link is what it points at. **A composed message with nowhere to answer is
not a message, and a link with no message is unreachable** — the two are the two halves of ruling
A2 and should be sequenced together, whoever pulls them. Nothing about the fence below changes.

### ⚠ The exception, and its fence

- **[[GTC-256]] Ruling 8** gives the host no `PARTICIPANT` token and no guest-side page. **This link
  is the single exception to that ruling.**
- **It answers only the carried item** — not the host's own items, not the adults of that
  household, not a child of any household that did not pick the host.
- **Widening it is widening a ruling, not fixing a gap**, and needs a founder ruling. The same
  fence A2 carries.

---

### What it meets — Do-Not-Touch Zone 3, and not solved here

- **The sweep.** `ensureEventTokens` in `src/lib/tokens.ts` deletes every `PARTICIPANT` token held
  by a `role: 'HOST'` row (`hostRowPersonIds`) each time it runs, and
  `tests/host-never-messaged-test.ts` asserts that revocation. A `PARTICIPANT` token for the host
  would be deleted by the next call, so the link cannot be one without changing the sweep and its
  test — the reach Ruling 8 exists to refuse. What it is instead is this ticket's to scope, under
  Zone 3 approval.
- **The page.** `GET` in `src/app/api/p/[token]/route.ts` returns the token holder's own
  assignments. Answering a carried item for an ordinary contact is [[GTC-191]]'s ([[GTC-189]]
  ruling D, item 3). The host's version is this ticket's, because the host has no guest page to
  extend.
- **"Narrow by construction."** The founder's words ask for a mechanism that cannot reach more than
  the carried item, not a check that happens to refuse more. Recorded as the bar scoping meets.

### Consequence recorded

- **A precondition of [[GTC-189]] slice 5 for the A2 case.** Ruling D item 3's rule — the press
  must not send a link to a page that cannot answer what the message asks — applies to the host as
  carrier. **Not added to the build shape here** — the founder's call.

### ⚠ THIS TICKET ALSO DISCHARGES AN UNPROVEN BRANCH IN [[GTC-189]] SLICE 5b

*Recorded 2026-09-19 on founder instruction, so the ticket that makes the case reachable knows it
also closes this.*

Slice 5b made the pre-flight count MESSAGES rather than recipients, and name every recipient the
press will not message with a reason. **The host as carrier is one of exactly two such states**
(`NONE_HOST_CARRIER`; the other, `NONE_NOT_ISSUED`, is unreachable for every role `PersonRole`
currently has), and its words were ruled the same day:

> *"Yours to pass on — I have no link to send you, so it's here rather than in a message."*

⚠ **THAT BANNER HAS NEVER RENDERED IN A BROWSER, AND IT CANNOT UNTIL THIS TICKET'S CASE EXISTS ON
A REAL BOARD.** Measured across all 29 events in `gather_dev` on 2026-09-19: `LinkState` reads
`READY` 63 and `AT_PRESS` 169, and **every `NONE_*` state is 0.** The A2 case — the host as another
household's picked contact, with a child of that household holding an item — occurs nowhere, which
GTC-189's own slice 5 finding already recorded is *"not the same as safe"*.

So the branch is **proven by construction** — a throwaway fixture in
`tests/preflight-withholding-test.ts` builds the A2 case and asserts the count, the split and the
words — **and unproven in use.** The founder's ruling on the distinction:

> Right to refuse the claim. Record that it closes when the A2 case exists on a real board, which
> is GTC-297's, and that a page probe proving the count line did not break proves nothing about a
> banner that never rendered.

**What this ticket owes it:** when the host's one-off link exists and the A2 case is reachable,
walk the pre-flight on a board that has one and confirm the not-messaged banner renders with that
sentence. ⚠ **And expect the words to need re-ruling at that point**, because this ticket changes
what is true of her: once she has a link she may stop being a not-messaged recipient at all, and
`NONE_HOST_CARRIER` may cease to have a population the way `NONE_COORDINATOR` did at [[GTC-294]].
If that happens, the state and its sentence go the same way — by the founder's own rule that a
state written after the gap closes is a state nobody has seen fire.
