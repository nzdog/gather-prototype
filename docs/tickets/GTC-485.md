  through `isDecideByExpired`): amber while there is time, red "maybe timed

  `src/lib/glance/read.ts`.

  red steps since the host's last look. The same change. Load: `rewind.ts`.

  follow-up is still owed and the "follow-up already sent" sentence. The same.

  carried, never shown.
- "Answers by" on the board's top line (`src/lib/events/event-dates.ts`
  `answersByDay`): event-level, no dish (ruled below).
- The maybe follow-up's finder (`decide-by-eligibility.ts`, the
  decide-by-followups cron every 15 minutes): who is due the one follow-up
  now. A maybe on an earlier session is followed up sooner. Zone 7.
- The follow-up's words (`decide-by-sender.ts`, `nudge-templates.ts`): "Still

export function neededBy(
  item: { dropOffAt: Date | null; day?: { date: Date } | null },
  event: LifecycleEvent
): Date {
  if (item.dropOffAt === null && item.day && isSessionsOn()) {
    const at = new Date(`${sessionDateKey(item.day.date)}T00:00:00.000Z`);
    return at.getTime() < event.endDate.getTime() ? at : event.endDate;
  }
  return item.dropOffAt ?? event.endDate;
}
