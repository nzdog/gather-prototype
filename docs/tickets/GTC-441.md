# GTC-441 - The sample marker, T2

> Filed by Claude Code on 1 Nov 2026 as a stub, from the plan for

## Scope

Every person made on a sample copy carries Person.sampleEventId (the
GTC-426 column), and a real event never matches one. capturePerson.ts
reads whether the event is a sample before its `if (email)`; on a
sample it matches only within the sample and stamps sampleEventId on
create, and on a real event its email match adds `sampleEventId:
null`. crowd.ts stamps each crowd person; copy.ts stamps the host
inside the copy's own transaction. No other create path runs on a
sample. Flagged, not fixed: tnz-reply-record.ts (Zone 7) flags every
Person with a phone number on STOP. New suite test:sample-identity
(about 20).

  before `if (email)`. On a sample the address match stays inside the
