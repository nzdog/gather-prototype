# [[GTC-106]] — Kate can't see the edges of what she's working on — CLOSED

**Status:** Complete | **Branch:** feat/moment-one-redesign | **Commit:** acb92f1

### What was found

- The Moment 1 input form (`Moment1InputForm.tsx`) rendered all form fields, household member buttons, and action buttons directly on the page background with no visual container. The assistant line, progress counter, and form content all sat in undifferentiated white space.
- The household card list (`HouseholdCardList.tsx`) rendered cards with no heading — households appeared silently in a column with no label.

### What was changed

**`src/components/plan/Moment1InputForm.tsx`** — Wrapped the household input fields (Name, Email, Phone, "Anyone else in this group?" section, and household member sub-forms) in a visual container: `border border-gray-200 bg-white rounded-xl p-6`. The assistant line ("Who's coming to [eventName]?...") and progress counter ("X people added.") sit above the container. The action buttons ("+ Add another person" and "Done adding people →" / "Save changes" and "Cancel") sit below the container with `mt-6` spacing. The container bounds only the workspace — not the chrome around it.

**`src/components/plan/HouseholdCardList.tsx`** — Added heading "Ducks in row so far" (`text-sm font-medium text-gray-500 mb-3`) above the card list. Only rendered when households exist (the component already returns null for empty lists).

### Known limitations

- The container background is `bg-white` on a white page — the border provides the visual boundary. If the page background changes, the container will still be distinct via the border.
