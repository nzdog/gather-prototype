# [[GTC-063]] — Highlight Invite Links card and add next step guidance on CONFIRMING screen — CLOSED

**Status:** Complete
**Branch:** gtc-042-part1-nudge-schema
**Commit:** c07aa25

### What was found
- The CONFIRMING screen is rendered in `src/app/plan/[eventId]/page.tsx`. Event status is detected via `event.status` and cards are conditionally rendered based on status.
- The Plan Frozen card (FROZEN status) uses `border-2 border-yellow-300` for its highlight style — amber/gold border with yellow icon background and text.
- The Invite Links card had no border or highlight styling — rendered as a plain white card with shadow, identical visual weight to other dashboard cards.
- The status description for CONFIRMING lived in `src/components/plan/EventStageProgress.tsx` with no guidance message below it.
- The invite links modal opens via `handleExpandSection('invites')` which sets URL param `expand=invites`, tracked by `expandedSection` state.

### What was changed

**`src/app/plan/[eventId]/page.tsx`**
- Added `inviteHighlightSeen` React state (session-only, no localStorage) — defaults to `false`
- Added useEffect that sets `inviteHighlightSeen = true` when `expandedSection === 'invites'` (i.e. when the host opens the Invite Links modal)
- Applied conditional highlight to Invite Links card: `border-2 border-blue-400 ring-2 ring-blue-100` when `event.status === 'CONFIRMING' && !inviteHighlightSeen`. This is visually distinct from the Plan Frozen yellow/amber style — uses blue border with a subtle blue ring glow.

**`src/components/plan/EventStageProgress.tsx`**
- Added guidance message below the CONFIRMING status description: a blue-tinted callout (`bg-blue-50 border-blue-200 text-blue-700`) with copy: "Share your invite links with guests and wait for them to confirm their items. Once everyone has responded, you can freeze the plan and lock it for the event."

### Known limitations / follow-up flags
- Highlight resets on page refresh (session state only, per ticket spec). This is intentional — no persistence mechanism needed.
