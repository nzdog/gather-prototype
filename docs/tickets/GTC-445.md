# GTC-445 - "Make the guests reply"

> Filed by Claude Code on 1 Nov 2026 as a stub, from the plan for
> GTC-392 parts C and D and the founder's rulings that day. Branch
> feat/demo-public from origin/main at df782c4. Planned, not built.

## Scope

On a sample copy only, the board gains a button (W49 to W54) in its
own client file beside the toggle, so GlanceBoard stays hook-free. It
calls a second shape, `{ demoReplies: true }`, on the existing POST
/api/events/[id]/households, read after its guard as the crowd's is
(Q7). No new route. src/lib/demo/replies.ts answers in one
transaction, through recordAssignmentAnswer (the guests' own writer),
so the board's replay shows the answers arriving. It refuses with W55
on any event that is not a copy, W53 if it has already run, and W56
with no guests. The mix is fixed by guest order and skips the fixed
guest: every 5th declines one item, every 4th says maybe, every 6th
does not answer, the rest accept, and itemless adults answer
attendance (one says no). It writes no message, no token, no sentAt.
New suite test:demo-replies (about 25).
