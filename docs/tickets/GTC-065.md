# GTC-065 — Reorder FROZEN screen cards and rename Wrap Up to Complete Event — CLOSED

**Status:** Complete
**Branch:** gtc-042-part1-nudge-schema
**Commit:** c1f487f

### What was found

**Card order mechanism:** Cards are hardcoded in JSX order within a CSS grid in `src/app/plan/[eventId]/page.tsx`. The grid renders cards in source order: Event Details, People, Items & Quantities, Teams, Plan Status, then conditionally Plan Frozen and Wrap Up. On the FROZEN screen, Plan Frozen appeared 6th and Wrap Up 7th.

**UI text locations found (all in `src/app/plan/[eventId]/page.tsx`):**
- Card title: "Wrap Up Event" (FROZEN) / "Wrapped Up" (COMPLETE)
- Card CTA: "Wrap up →"
- Modal title: "Wrap Up Event" (FROZEN) / "Wrap-Up Status" (COMPLETE)
- Modal heading: "wrap up {event.name}?"
- Button labels: "Yes, wrap up anyway", "Wrap up & send thank-you messages"
- Loading states: "Wrapping up..."
- Error message: "Failed to wrap up event."

### What was changed

**`src/app/plan/[eventId]/page.tsx`:**
1. **Card reorder** — Moved Plan Frozen card and Complete Event card from after Plan Status to before Event Details in the grid. On the FROZEN screen, Plan Frozen is now first and Complete Event is second. Remaining cards follow in their existing order.
2. **Rename — card title:** "Wrap Up Event" → "Complete Event", "Wrapped Up" → "Event Complete"
3. **Rename — card CTA:** "Wrap up →" → "Complete event →"
4. **Rename — modal title:** "Wrap Up Event" → "Complete Event", "Wrap-Up Status" → "Completion Status"
5. **Rename — modal heading:** "wrap up {event.name}" → "complete {event.name}"
6. **Rename — button labels:** "Yes, wrap up anyway" → "Yes, complete anyway", "Wrap up & send thank-you messages" → "Complete event & send thank-you messages"
7. **Rename — loading states:** "Wrapping up..." → "Completing..."
8. **Rename — error message:** "Failed to wrap up event." → "Failed to complete event."
