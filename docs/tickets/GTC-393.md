# GTC-393 - The by-hand reminder and the thank-you can send on a real event with no Send

> Stub, filed 18 Oct 2026 on Nigel's ruling at GTC-392 Q13: "A ticket of
> its own for Cowork to scope (Recommended)". Not scoped, no severity.
> GTC-392 part A shuts both doors for sample (demo) events only; this
> ticket is about real events.

## The gap (found planning GTC-392, read at `aef41af`; its correction 3)

Two doors send with NO press, so "an event is never pressed" does not
shut them:

- The by-hand nudge,
  `POST /api/events/[id]/people/[personId]/nudge`, checks no sent state.
  It sends directly (`sendSms`, `sendNudgeEmail`). A host can text or
  email any guest on her event at any time, with words she types, whether
  or not the event was ever sent. On a paid event the $25 is the only
  barrier between a stranger and Gather texting any number they add as a
  guest.
- Wrap-up, `POST /api/events/[id]/wrap-up`, checks only that the event is
  over (`isComplete`), not that it was sent. It writes `WrapUpLink` rows
  that `/api/cron/wrap-up-dispatch` sends by text and email. An event
  whose dates have passed, never sent, can thank every guest.
