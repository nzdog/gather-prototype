The full write-up (reasons, rulings, severity and the follow-up

## What it changes

When a host types a guest (add person, CSV import, new household,
household edit), `src/lib/households/capturePerson.ts` decides whether
the typed row is an existing guest record or a new one. It now:

- trims the typed address and compares it with stored addresses as
  plain text (outer spaces off, capitals ignored);
- on a real event, reuses an existing record only among the same
  host's own people: the event's own host (`Event.hostId`; a co-host
  adding people to a host's event matches among that host's people)
  and the people on that host's real events;
- also finds a record with an email opt-out on one of that host's real
  events, so an unsubscribe still holds when a removed guest is typed
  back.

Samples keep their own scope; only the trim and the plain-text
comparison are new there. The first-name rule and "the host's own
record first" are unchanged. The four places that call the helper are
unchanged.

Files: one app file (capturePerson.ts), tests, one package.json script
line (`test:guest-per-host`) and this ticket. No migration, no schema
change, no page change, no route added or removed, no zone file, no
frozen file.

## Tests that moved

- **New: tests/guest-per-host-test.ts**, `npm run test:guest-per-host`,
  25 checks. It calls the helper directly, against gather_demo only,
  with made-up hosts, events and guests (`example.test` addresses,
  names like "Alex Test"). It refuses to run if live sending is on, an
  in-process guard refuses any connection off this machine, and every
  row it makes is deleted at the end. A dry run with no database:
  `GUEST_PER_HOST_DRY_RUN=1`.
- **tests/shared-address-test.ts**: D2 and E3 rewritten by founder
  ruling to the new matching rule. D2 is now three checks, so the
  suite goes from 30 checks that run to 32. E3 puts the people it makes
  on its event first, as the real entry points do.
- **tests/decide-later-settle-test.ts**: item 12 (12.0, 12a.3, 12b.6)
  rewritten by founder ruling: the second host's row has a record of
  its own, which keeps the email and phone that host typed. Still 62
  checks.
