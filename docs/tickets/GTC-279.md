## The decision

**GitHub's Dependabot alert count for this repository is structurally wrong,
and will stay wrong forever, because `master` is the default branch and nothing
merges into it.**

Dependabot always scores the default branch. The default branch is `master`, at
`ebc21d9` (2026-08-10, *"chore: verify Railway auto-deploy disabled
(GTC-227)"*). Day-to-day work happens on `feat/moment-one-redesign`, which is
320 commits ahead of the merge-base `b28204b` (2026-04-10) and has **diverged**
— `origin/master` is not an ancestor of the working branch.

Consequence, measured 2026-09-12 in [[GTC-277]] Finding 1: GitHub reported **75
open alerts** (35 high, 35 medium, 5 low). Of those, **36 were already dead on
the working branch** — cleared by fixes that shipped in [[GTC-243]] and
[[GTC-245]] and that GitHub has never seen — and **2 more** name packages that
have left the tree entirely. Meanwhile **5 advisories live on the working
branch had no GitHub alert at all, including both Next.js criticals.**

**The count was 38 too high and blind to the two most severe live findings,
simultaneously.** Every future alert will have the same defect until the
default branch reflects shipped code.

## Why this is filed rather than fixed

Both available remedies are founder calls with consequences well outside a
dependency ticket:

1. **Merge `feat/moment-one-redesign` into `master`.** 320 commits. Touches
   the deploy story — `GATHER-BUILD-CONSTANTS.md` records that Railway
   auto-deploy from `master` was turned off on 2026-08-10, so merging no longer
   deploys by itself, but the caveat in that same section stands: turning off
   auto-deploy decouples deploy *timing*, not the database. Schema migrations
   still apply the moment code carrying them is deployed and run.
2. **Repoint the GitHub default branch to `feat/moment-one-redesign`.** A
   one-click change that would make the alert count meaningful immediately.
   Consequences: changes the base of new PRs, changes what `git clone` checks
   out, and formalises in GitHub's UI a convention the constants file already
   describes in prose ("`feat/moment-one-redesign` — this is the working trunk
   in practice… `master` is not the active integration target").

Option 2 is the cheaper of the two and does not touch deploy or the database.
That is an observation, not a recommendation — the call is not the executor's.

## Until it is decided

**Do not triage from GitHub's alert count.** Scope dependency work against
`npm audit` run directly on the branch being fixed. That was [[GTC-243]]'s
recommendation in August, it was re-confirmed by GTC-277, and it holds until
this ticket closes.
