# [[GTC-120]] — Toggle thumb not sliding — CLOSED

**Status:** Complete | **Branch:** feat/moment-one-redesign | **Commit:** d8ecd1e

### What was found

The `ToggleRow` component in `Moment2Step1Modal.tsx` used `translate-x-4.5` and `translate-x-0.5` for the thumb position. These are not valid Tailwind utility classes — Tailwind does not generate `.5` fractional variants for `translate-x`. The classes were silently ignored, so the thumb stayed at `translate-x: 0` in both states. The track colour changed correctly (`bg-accent` vs `bg-gray-300`) but the thumb never moved.

The "Still deciding?" controls are text buttons, not toggle switches — they don't have a thumb and were not affected.

### What was changed

**File modified:** `src/components/plan/Moment2Step1Modal.tsx`

- Replaced `translate-x-4.5` with `translate-x-[18px]` (on state — thumb slides right)
- Replaced `translate-x-0.5` with `translate-x-[2px]` (off state — thumb at left edge with small inset)

Both use Tailwind arbitrary value syntax which generates the correct CSS. The existing `transition-transform` class on the thumb ensures smooth animation.
