# GTC-444 - A sample reaches the board; Host / Guest

> GTC-392 parts C and D and the founder's rulings that day. Branch
> feat/demo-public from origin/main at df782c4. Planned, not built.

## Scope

A sample reaches the board by a link, with nothing marked sent (Q4
(A); QB2 stands). In the pre-flight, right after the pretend panel, a
new `SampleBoardLink` in its own file draws W42 to /plan/[id]/glance,
beside the panel, not in it. On the board, a sample note W43 says what
amber means there. On a sample copy only, the board gains a small
Host / Guest toggle (W44 to W47). The fixed guest is Aroha Ngata when
the crowd is there, else the first typed guest with a PARTICIPANT link
(Q5). Its token is read by a helper in src/lib/demo, not in the page.
GET /api/p/[token] skips the host preview when the event is a sample
copy, so the visitor sees the guest's own page and answers through the
real routes. On a copy the guest page gains W48 back to the board.
New suite test:demo-board (about 25).
