# [[GTC-046]] — Verify wrap-up dispatch cron is configured and firing in production — CLOSED

**Status:** Complete
**Branch:** gtc-042-part1-nudge-schema
**Commit:** pending

### What was found

**Cron endpoint requirements (`/api/cron/wrap-up-dispatch`):**
- Methods: GET and POST both accepted
- Auth: `CRON_SECRET` via `Authorization: Bearer <secret>` header or `?secret=<secret>` query param
- Purpose: Calls `dispatchPendingWrapUpMessages()` which dispatches wrap-up thank-you messages that have been pending for 10+ minutes (`DISPATCH_DELAY_MINUTES = 10`)
- No request body required

**Scheduler config status: MISSING (critical gap)**

The project uses Vercel crons configured via `vercel.json`. Before this fix, `vercel.json` only contained the nudges cron:
```json
{
  "crons": [
    {
      "path": "/api/cron/nudges?secret=${CRON_SECRET}",
      "schedule": "*/15 * * * *"
    }
  ]
}
```

The `/api/cron/wrap-up-dispatch` endpoint was **not configured** in any scheduler — not in `vercel.json`, not in any `railway.toml` (does not exist), and not documented in GATHER-BUILD-CONSTANTS.md.

**Note:** The project deploys via Vercel, not Railway. No `railway.toml` or Railway config files exist in the repo.

**All cron endpoints in codebase (2 total):**
1. `src/app/api/cron/nudges/route.ts` — SMS auto-nudges (was configured, every 15 min)
2. `src/app/api/cron/wrap-up-dispatch/route.ts` — wrap-up message dispatch (was NOT configured)

### What was changed

| File | Change |
|------|--------|
| `vercel.json` | Added wrap-up-dispatch cron entry: `*/10 * * * *` schedule, passes `CRON_SECRET` via query param (matching nudges pattern) |
| `GATHER-BUILD-CONSTANTS.md` | Added wrap-up-dispatch to the cron routes documentation table |

### Known limitations / follow-up flags

- **Vercel cron deployment:** The `vercel.json` change will take effect on next deploy. Verify in the Vercel dashboard (Project Settings > Crons) that both cron jobs appear after deploy.
- **CRON_SECRET env var:** Must already be set in the Vercel production environment (it should be, since the nudges cron was already using it).
- **Vercel Hobby plan limitation:** Vercel Hobby plans support only 2 cron jobs. If the project is on Hobby, both crons fit exactly. Adding a third would require upgrading to Pro.
