### Scope

`GATHER-BUILD-CONSTANTS.md:108-112` carries a "pre-existing known issue" that is **confirmed
stale**:

> **Pre-existing known issues (do not fix without a dedicated ticket):**
> - DB schema drift (P3005): `gather_dev` schema was applied outside migration history.
>   `prisma migrate dev` detects drift and prompts for reset; `prisma migrate deploy` errors
>   with P3005. The DB is functional — security tests confirm connection. Fix requires
>   baselining the existing schema.

**Confirmed stale by two live `prisma migrate status` runs**, not by inference. The confirmation
pass ran it directly against `gather_dev` at localhost:5432:

```
33 migrations found in prisma/migrations
Database schema is up to date!
```

No drift, no reset prompt. Corroborated by GTC-171 (`e85ebfa`) and GTC-172 (`63764d1`), which
each independently recorded the same clean result on 2026-08-04 (at 32 migrations), and by the
migrations applied since. The file has not been touched since `9eb6069` (GTC-153).

**Why this is worth a ticket rather than a drive-by edit: it is read by every executor.** It sits
in the ticket-template preamble — step 1 of every GTC ticket:

- `BUG-TICKET-TEMPLATE.md:7` — *"1. Read GATHER-BUILD-CONSTANTS.md in full"*
- `BUG-TICKET-TEMPLATE-FULL.md:141-142` — *"Locate GATHER-BUILD-CONSTANTS.md in the repo root / Read it in full"*
- `UX-TICKET-TEMPLATE.md:4` — *"Read GATHER-BUILD-CONSTANTS.md in full"*

Two tickets have already each burned a verification step disproving it. A third and fourth will
until it is fixed.

**Fix it where it is actually read — the constants file at the repo root.** ⚠ **NOT** the
discovery report (`docs/04_roadmap/moment4-hinge-discovery-report.md`). The warning was
originally attributed there, and that attribution is wrong: `grep -inE "p3005|drift|build-constants|migrate status"`
over all 181 lines of the report returns **zero hits** — it has no build-environment section and
is not reachable to the warning by any pointer. Correcting the report would leave the actual
stale warning untouched at the repo root.

**Sweep scope, to be ruled when pulled.** P3005 also appears in `GATHER-KNOWN-BEHAVIOURS.md` and
five skills (`gather-data-model-and-migrations`, `gather-build-and-env`, `gather-debugging-playbook`,
`gather-failure-archaeology`, `gather-change-control`, `gather-docs-and-writing`), plus historical
mentions in GTC-080/147/171/172 that are **correct as history** and should be left alone. Decide
whether this ticket is the constants file only or the full sweep; do not silently do half.
