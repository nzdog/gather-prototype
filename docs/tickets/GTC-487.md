## What planning found (28 Nov 2026)

**A. The red panel** is `src/components/glance/PersonSurface.tsx`, a
different file from the green and amber reading panel
(`GlancePersonReading.tsx`). Each of its rows already carries the
session's name: `src/lib/glance/read.ts` sets `session` on a held row
only while the switch is on and the dish has a session ([[GTC-485]] F),
and the board's live poll hands the same rows on. GTC-485 drew it on
the reading panel only, by its plan ("The reading list only;
PersonSurface.tsx and GlanceBoard.tsx are not changed"). So A is drawing
only. PersonSurface's header says "No plan content beyond the row's own
name"; it gets a dated note.

**B. Why "1 pieces".** Almost every dish stores its unit as words: the
plan's write (`plan-write.ts`) stores the AI's unit word as
`quantityUnit: 'CUSTOM'` with the word in `quantityUnitCustom`, and
Moment 2's unit list saves a picked word the same way as a typed one
(`setup/page.tsx`, the edit and add paths). So a picked "trays" and a
typed "trays" cannot be told apart. The board's label (`reading.ts`,
`quantityLabel`) already reads "1 tray" for the few old rows stored as a
fixed unit, and leaves words as they are by an earlier ruling ("A
CUSTOM UNIT IS THE HOST'S OWN WORD, LEFT EXACTLY AS SHE TYPED IT").

**B. Messages: none carries a quantity.** The invitation names the
dishes only (`ask-register.ts`: "The message NAMES the items; it does
not carry their logistics"; "bring the pavlova"). The nudges, the
decide-by follow-up and the thank-you use names only. The guest page's
amount helper says "Amounts stay off the message text." No message file
is touched, and no zone is near.

**B. Every screen where a quantity and its unit meet**, grouped by the
code they share today:

- Shared piece 1, the setup page's unit word (`mapItemUnitToDisplay`,
  `src/app/plan/[eventId]/setup/page.tsx`):
  - Moment 2, the plan: each dish's quantity button
    (`Moment2PlanView.tsx`, `{item.quantity} {item.unit}`).
  - Moment 2, the box for typing a new amount: the unit word beside it.
  - Moment 3, each dish's row and its Details box (`item.detail`, built

    child's rows;

  - Moment 3's rows after a dish is shared out;
  - Moment 3's share box: the unit word beside the amount she types.
- Shared piece 3, the board's label (`quantityLabel`,
  `src/components/glance/reading.ts`):
