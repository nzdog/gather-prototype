**Go fix it navigation preservation:**

`ConflictCard.onGoFixIt` extracts team name from `conflict.affectedParties[0]` ([[GTC-093]]). It does NOT read `conflict.suggestion`. Navigation is unaffected.

For `detectMissingCoordinators`, the team name was previously only in `suggestion.teamName`. Added `affectedParties: [team.name]` to the coordinator conflict data so "Go fix it →" can still extract the team name via `affectedParties[0]`.
