# GTC-040 — Plan/Dashboard: Merge Plan Assessment + Gate Check into Plan Status, reorder cards

Type: UX
Severity: P2

## The Fix

1. Merged Plan Assessment and Gate Check / Freeze Check into a single "Plan Status" card and modal
2. Reordered dashboard cards to match natural host workflow
3. Removed "Check Plan" button from page header

### Card order

**DRAFT:** Event Details, People, Items & Quantities, Teams, Plan Status, Revision History

**CONFIRMING:** Event Details, People, Items & Quantities, Teams, Plan Status (includes Freeze button), Invite Links, Revision History

**FROZEN / COMPLETE:** Event Details, People, Items & Quantities, Teams, Plan Status, Plan Frozen (unfreeze), Invite Links, Revision History

### Plan Status card

- Card label: "Plan Status"
- Summary: conflict count + readiness status (e.g. "0 conflicts · Ready to freeze" or "2 conflicts · 4 unassigned")

### Plan Status modal

- **Conflicts** section — always visible, shows existing ConflictList component
- **Freeze Readiness** section — only visible when event is in CONFIRMING status, includes FreezeCheck component with Freeze button

### Header

- "View as Host" and "Generate Plan / Regenerate Plan" buttons remain
- "Check Plan" button removed (function still accessible via setup checklist banner)
