# GTC-194 — J3: The runbook — printable run sheet

**Status:** Open | **Branch:** TBD | **Commit:** [pending] (filed `e5f6e82`) | **Effort:** xhigh

*Effort level is a proposal from the discovery-report ticket breakdown — run `/effort` manually
before execution.*

### Context

Moment 4 spec §6: the runbook is an ownership artifact, not an information artifact — the same
job as the pavlova row, done with the washing-up. Tasks (B2, GTC-171) enter alongside items,
assigned through the same machinery. It lives **on the fridge**: a downloadable, printable run
sheet — nobody opens an app at 2pm with wet hands. §8.8: the sheet carries a per-row mark-here
affordance (a tick box or equivalent) — capture now, resolve in the system later. Print date on
the sheet, and a changes-since-print reprint offer on the screen. **The stop-line:** no day-of
mode, no live check-off, no event-mode screen — the printout is the last artifact before the day.

Today: a "Download PDF" button exists (browser print-to-PDF of a raw item table — no critical
badges, no tasks, no tick-boxes, no print-date) and a separate "Copy plan as text" clipboard
export. Both render raw plan content, which §3 explicitly refuses for the day-to-day screen (they
live in V1 surfaces, not the not-yet-built Moment 4 screen, so they aren't a direct contradiction
of J1 — but they are not the runbook either).

### Scope

**Fix here:**
- Real print/export generation for the runbook, including B2's task rows alongside items, J2's
  criticality badges, and per-row tick-box affordances.
- Print-date stamping on the sheet.
- A changes-since-print detector, surfaced as a reprint offer on J1's screen.

**Do not touch:**
- All Do-Not-Touch Zones in `GATHER-BUILD-CONSTANTS.md`.
- Any live check-off / day-of mode — **explicitly refused by the spec; do not build it even as a
  stretch goal or a "nice to have while we're in here."**
- The existing V1 "Download PDF" / "Copy plan as text" — leave them as-is unless retiring them is
  separately in scope; this ticket builds the runbook as a new artifact, not a rewrite of those.

### Dependencies

J1 (GTC-192), B2 (GTC-171).
