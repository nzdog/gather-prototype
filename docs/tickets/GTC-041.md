# [[GTC-041]] — Plan/Modals: Inter-modal navigation tab bar + Generate Plan CTA in empty Items & Quantities

Type: UX
Severity: P2

## Evidence (Executor-Completed)

### What was built
Added an inter-modal navigation tab bar and breadcrumb to all plan page modals, allowing hosts to jump between sections in one click. Added a "Generate Plan" CTA in the empty Items & Quantities modal.

**Tab bar features:**
- Present in all plan page section expansion modals (Plan Status, Items & Quantities, People, Teams, Invite Links, Revision History) and the Edit Event Details modal
- Tabs follow workflow order varying by event status:
  - DRAFT: Details · People · Items · Teams · Plan Status · History
  - CONFIRMING/FROZEN/COMPLETE: Details · People · Items · Teams · Plan Status · Invites · History
- Active tab highlighted with accent color underline
- Clicking any tab closes current modal and opens the target modal
- Icons match the dashboard card icons (Calendar, Users, Package, Users, AlertCircle, LinkIcon, Clock)

**Breadcrumb:**
- Shows "Plan › [section]" navigation path
- Clicking "Plan" closes the modal and returns to the dashboard
- Intermediate crumbs are clickable to navigate back through the trail

**Empty Items CTA:**
- When Items & Quantities has no items, shows "No items yet. Generate a plan or add items manually."
- "Generate Plan →" button opens the HostDescriptionModal (Quick Generate / Guided Build choice screen)
- "+ Add Item" button opens the AddItemModal
- Both buttons only visible in DRAFT status

**Teams empty state CTA:**
- When Teams modal has no teams, shows "No teams yet. Generate a plan to create teams automatically." with Generate Plan → and + Add Team buttons
- Matches the Items & Quantities empty state pattern

**Plan Status empty state:**
- When no plan exists (items and teams both empty), the Conflicts section shows "No plan yet · Generate a plan to check for conflicts" with a Generate Plan → button instead of the misleading "No conflicts found · Your plan is looking great!"
- "No conflicts found" message now only appears when a plan exists but has zero conflicts
