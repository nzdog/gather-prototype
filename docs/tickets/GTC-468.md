All dates are NZ time.

## Why (the finding)

Pull request 107 added "Your contacts": a page where a host loads a
list of guests (paste, CSV, vCard, the phone's picker) and a way to
pick from it on Moment 1. The code has no sample check, so:

- A sample visitor (a throwaway account at the demo-copy.invalid
  domain) sees "Your contacts" in the menu bar
  (src/components/shared/Navigation.tsx), and the W31 box and link in
  Moment 1 (src/components/plan/Moment1InputForm.tsx).
- She can open /plan/contacts and load a list.
- That list stays in her browser, under the throwaway account. Nothing
  removes it when the sample is deleted. The privacy line W58 says Gather
  deletes the sample "and everything you type into it" the next day.
  For a loaded list that would be untrue.
- The sample banner already says "Use made-up names."
- public/explainer/m1-add-crowd.jpg (830 by 594) shows Moment 1 with one
  household and no contacts box, so it no longer matches the screen.
- src/lib/demo/explainer-words.ts, Moment 1, never names contacts.

All of this was checked against the code on 22 Nov 2026 (plan, read
only). One extra find, not fixed here: the toast (the small notice that
slides in, src/contexts/ToastContext.tsx) has no screen-reader role, so
a blind visitor would not hear it. W59 has the same gap (Q9, below).

## How each screen tells it is a sample (Q6 option 1)

- Menu bar: isCopyAddress(user?.email), the existing check for a
  throwaway account address.
- Moment 1: the event's own isDemo flag, which the setup page already
  holds. The setup page passes Moment 1 one new optional prop,
  onSampleContacts. Moment 1 has no toast of its own and gets no hook (a
  hook is a React call that must run on every draw; several tests draw
  Moment 1 without the toast machinery).
- The contacts page: a new tiny client file, SampleViewer.tsx, holds a
  yes/no context. layout.tsx sets it from isCopyAddress(user?.email).
- The old shared sample (an isDemo event whose host is not a copy
  account) was retired by GTC-442; no visitor can start one. Moment 1
  would show the pop-up there (isDemo); the menu bar and the page would
  not. Harmless today.
