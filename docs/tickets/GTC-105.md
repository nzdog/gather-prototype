# GTC-105 — Moment 1: Completion summary — CLOSED

**Status:** Complete | **Branch:** feat/moment-one-redesign | **Commit:** ce4448f

### What was found

- MomentArc component (`src/components/plan/MomentArc.tsx`) only accepted `currentMoment` with no concept of completed moments. Needed a `completedMoments` prop to show checkmarks.
- Parent page (`src/app/plan/[eventId]/page.tsx`) had `showMoment1` state but no phase distinction between input and summary views. The `onComplete` callback from Moment1InputForm directly closed Moment 1.
- `SavedHousehold` type already exported from `HouseholdCardList.tsx` — no need to extract to a shared file.
- PUT endpoint (`/api/events/[id]/households/[householdId]`) accepts full household payload for updates, suitable for inline contact detail additions.

### What was changed

**`src/components/plan/MomentArc.tsx`** — Extended with optional `completedMoments?: number[]` prop. Completed moments show green circle with checkmark, full opacity, and green text with "✓" suffix. Backwards compatible — existing callers unaffected.

**`src/components/plan/Moment1Summary.tsx`** — New component. Full-screen summary view with:
- MomentArc showing Moment 1 as done, Moment 2 as current
- Headline stats: people count, households, children (if >0), missing contacts (if >0)
- Completion sentence (hidden when zero people)
- Missing contacts list with "Add now" (inline form → PUT endpoint) and "Skip for now" (removes from view, stats unchanged)
- "+ Add more people" link (calls onBackToEditing)
- "On to the plan →" button (calls onContinue)

**`src/app/plan/[eventId]/page.tsx`** — Added `moment1Phase` state (`'input' | 'summary'`). "Done adding people →" now transitions to summary phase. "On to the plan →" exits Moment 1 entirely. "+ Add more people" returns to input phase with existing households preserved.

### Known limitations

- The "Add now" inline form sends the full household payload via PUT. If two people in the same household are both missing contacts and are updated in quick succession, the second update uses a stale local copy. Unlikely in practice (Kate updates one at a time).
- "Skip for now" is view-only — refreshing the page will re-show skipped contacts.
