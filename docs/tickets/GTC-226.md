# GTC-226 — Collapse the skill's citation bullets to a pointer

**Status:** Open — unassigned, not started. **Effort:** Low.
**Gated on:** nothing. Can be pulled any time.

*Source: [[GTC-222]], observed one session after it closed.*

### Why

[[GTC-222]] argued that a rule duplicated three ways drifts three ways. It then put the
canonical Citations section in `BUG-TICKET-TEMPLATE.md` and, in the same pass, restated four
of its rules as house-style bullets in `gather-docs-and-writing`.

A fifth rule was added later that day — *verify the name exists at HEAD; symbol form is not
proof* (`5e318c7`). It landed in the template. It did not land in the skill.

**That is [[GTC-222]]'s own argument demonstrating itself inside a single session**, on the
shortest possible timescale, between two files edited by the same author hours apart. The
duplication did not survive one addition.

Restoring parity — adding the fifth bullet to the skill — fixes today and guarantees the next
divergence. Pointing closes the class. This ticket points.

### Scope

**Not a sync. A deletion plus a pointer.**

In `.claude/skills/gather-docs-and-writing/SKILL.md`, House style currently carries four
citation bullets, roughly 33 lines:

1. *Cite code by symbol name, never by line number* — including the GTC-211 worked example
   and the last-resort line-number-plus-hash escape hatch
2. *ANCHOR tokens for locations with no symbol*
3. *A comment records WHY, or that a state is provisional — never WHAT the code does*
4. *A deliberate temporary state carries the ticket ID that ends it*

Delete all four. Replace with one bullet pointing at the Citations section of
`BUG-TICKET-TEMPLATE.md` as the binding, canonical statement — matching the pointer already
approved into `GATHER-BUILD-CONSTANTS.md` (`9bccf42`), which deliberately does not restate the
rules either.

**Keep** the GTC-211 worked example if it is judged to carry weight the template's version
does not, but keep it as *evidence*, not as a restatement of the rule. That is a judgment call
for whoever pulls this; the default is to let it go, since the template carries the same case.

**One item needs a decision, not a default.** The Evidence-section discipline checklist in the
same skill reads *"Root cause stated with symbol-level code evidence, not narrative"* — amended
from `file:line` by [[GTC-222]]. That is a checklist item that *invokes* the rule rather than
restating it, so it is arguably fine as-is. Rule or invocation is the call to make; if it
counts as a restatement, it gets the same pointer treatment.

### Explicitly out of scope

- `gather-validation-and-evidence`, which carries its own *"Cite code by symbol, not line
  number"* with a distinct and useful reason (line numbers drift between the fix commit and
  the hash-backfill follow-up). It already ends by deferring to the full rule elsewhere.
  Whether it also collapses to a pointer is a separate decision — **do not sweep it in
  without ruling on it**, since its reason is not duplicated anywhere else and would be lost.
- `gather-frontier-and-roadmap`, corrected by [[GTC-222]] and carrying no rule statement.
- The template itself. This ticket changes no canonical text.

### Acceptance

- [ ] The four citation bullets are gone from `gather-docs-and-writing` House style.
- [ ] One pointer bullet names the Citations section of `BUG-TICKET-TEMPLATE.md` as binding.
- [ ] No rule text is restated in the skill — verify by reading the pointer in isolation and
      confirming it teaches nothing, only redirects.
- [ ] A decision is recorded on the Evidence-checklist item above, either way.
- [ ] `gather-validation-and-evidence` is untouched, or a ruling to include it is recorded.

### Stop Conditions

Standard eight from `BUG-TICKET-TEMPLATE.md`. Additionally: if deleting a bullet would lose
reasoning that exists nowhere else, stop and report rather than deleting it — move it to the
canonical section first, in a separate pass.
