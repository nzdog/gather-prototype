[[GTC-029]] — Plan/Host: "View as Host" button silent failure and misleading alert
Severity: [ ] Critical [ ] High [x] Medium [ ] Low
Escalated (brand/trust risk): [ ] Yes [x] No

Signal
Expected
On a CONFIRMING event, clicking "View as Host" opens the host monitoring view in a new tab. If the host link is unavailable for any reason, the user sees an accurate message explaining why.
Actual
On a CONFIRMING event where loadInviteLinks has failed silently, clicking "View as Host" fires an alert: "Host view is not available yet. Please transition to CONFIRMING status first." — factually wrong, the event is already CONFIRMING. The API failure is swallowed with console.error only, leaving inviteLinks empty with no user feedback.
Smallest failing case
Open any CONFIRMING event where loadInviteLinks has failed → click "View as Host" → observe misleading alert blaming event status.

Evidence (Executor-Completed)

Root cause confirmed
Two issues in `src/app/plan/[eventId]/page.tsx`. First: the `loadInviteLinks` failure handler (response not ok branch) only called `console.error` and returned, never setting any visible state — leaving `inviteLinks` empty with no indication to the user. Second: the "View as Host" button's fallback alert was a hardcoded string ("Please transition to CONFIRMING status first") with no awareness of the current event status, so it fired the wrong message even when the event was already CONFIRMING, FROZEN, or COMPLETE.

Files changed
- `src/app/plan/[eventId]/page.tsx` — added `inviteLinksError` state; set it to `true` on `loadInviteLinks` failure and `false` on success; updated "View as Host" fallback to branch on `event.status` (DRAFT keeps original message, all other statuses show "Host link unavailable — try refreshing the page"); added inline error span below the button when `inviteLinksError` is true.
- `tests/view-as-host-alert-test.ts` — new regression test (9 assertions covering DRAFT/CONFIRMING/FROZEN alert messages, successful open path, and inviteLinksError state transitions).
- `package.json` — added `test:view-as-host-alert` script.
