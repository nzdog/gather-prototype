# GTC-111 — Kate can barely see where she's heading — CLOSED

**Status:** Complete | **Branch:** feat/moment-one-redesign | **Commit:** 7c56f6f

### What was found

Inactive moments in `MomentArc.tsx` used `opacity-40` on the container element, stacking on top of already-light text (`text-gray-400`) and circle (`bg-gray-200 text-gray-500`) colors. The compounded effect made future steps nearly invisible against the background — roughly 16% effective contrast on the text. The number circles were slightly more visible but still too faint to read comfortably.

### What was changed

**File:** `src/components/plan/MomentArc.tsx`

Two targeted changes to inactive moment styling:

1. **Container opacity:** `opacity-40` changed to `opacity-70` — inactive moments are now clearly visible while remaining visually secondary to the active moment
2. **Text color:** `text-gray-400` changed to `text-gray-500` — label text is now comfortably readable

**Unchanged:**
- Active moment styling (`bg-accent text-white`, `text-gray-900 font-medium`) — untouched
- Completed moment styling (`bg-green-600 text-white`, `text-green-700 font-medium`, checkmark) — untouched
- Number circle colors for inactive (`bg-gray-200 text-gray-500`) — already adequate at the new opacity
- Arc layout, spacing, and responsive behaviour — untouched

### Known limitations

None. This is a pure CSS class change with no behavioural side effects.

### Acceptance met

- **Felt:** All four moments are readable at a glance. Future steps feel like a clear path, not a faded afterthought.
- **Functional:**
  - Inactive moments have increased text and circle contrast (opacity 40% -> 70%, text gray-400 -> gray-500)
  - Active moment styling unchanged
  - Completed moment styling unchanged
  - Arc is legible on both desktop (row layout) and mobile (column layout)
- **Must never violated:** No — inactive moments remain visually secondary to the active moment; layout/spacing untouched; completed styling untouched.
