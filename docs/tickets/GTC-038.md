# GTC-038 — Plan/Items: Items & Quantities redesign — accordion groups, three-column layout, sorted by category

**Type:** UX
**Severity:** P2

## The Person
A host opening Items & Quantities after generating a plan with 47 items across 6 categories. They see a long flat list with cards. They have to scroll endlessly to find items in a specific category. The list is hard to scan and manage.

## The Broken Promise
Items & Quantities should give the host a clear overview of what's been generated and make it easy to review by category. A flat scrolling list of 47 cards doesn't do that.

## The Cost
Hosts lose confidence in the plan output. Managing items feels overwhelming rather than clear.

## The Fix
1. Group items by category (team name) — sorted alphabetically, no split groups
2. Accordion per category group — header shows category name + item count, collapsed by default, click to expand/collapse with smooth animation
3. Three-column table layout inside each accordion: Item (with badges + quantity) | Category | Edit
4. Items sorted by team name before grouping — no category appears in two separate places
