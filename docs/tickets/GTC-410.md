## The Mac change (outside the repo)

Before: node v20.20.2, npm 10.8.2, from Homebrew's node@20. Line 3 of
~/.zprofile was:

```
export PATH="/opt/homebrew/opt/node@20/bin:/opt/homebrew/opt/postgresql@16/bin:$PATH"
```

Done, in order:

```

sed -i '' '3s#/opt/homebrew/opt/node@20/bin#/opt/homebrew/opt/node@22/bin#' ~/.zprofile
```

After, line 3 is:

```
export PATH="/opt/homebrew/opt/node@22/bin:/opt/homebrew/opt/postgresql@16/bin:$PATH"
```

Proved in a fresh login shell (zsh -l -c): node v22.23.4, npm 10.9.9;
/opt/homebrew/opt/node@20/bin/node --version still prints v20.20.2.
node@20 was neither unlinked nor removed.

What Homebrew changed (brew list before and after):

- Added: node@22 22.23.4, and four packages it needs: libnghttp3 1.18.0,
  simdjson 5.0.5, sqlite 3.54.1, uvwasi 0.0.23.
- Upgraded, despite HOMEBREW_NO_INSTALL_UPGRADE (that setting only stops
  the formula being installed from upgrading; Homebrew still upgrades
  outdated packages the new one depends on): brotli 1.2.0 -> 1.2.1,
  c-ares 1.34.6 -> 1.34.9, ca-certificates 2026-05-14 -> 2026-10-20,
  libnghttp2 1.69.0 -> 1.70.0, libuv 1.52.1 -> 1.53.0, readline 8.3.3 ->
  8.3.6, xz 5.8.3 -> 5.8.4. All seven are in node@22's own dependency
  tree (brew deps node@22). readline and xz are shared with
  postgresql@16.
- Checked after: node@20 runs (zlib, brotli, crypto); psql 16.14 and the
  running Postgres server answer (pg_isready, a query on gather_demo);
  gh 2.100.0 runs. Nothing broken, so no stop.

Then, in this folder: rm -rf node_modules .next; npm ci (477 packages,
no change to package-lock.json or package.json); npm run db:generate
(Prisma Client 6.19.3). git status showed only the two untracked
scripts.

Moving ~/.zprofile moves EVERY Node project on this Mac to Node 22, not
only Gather, in every new terminal. Shells opened before the change keep
Node 20 until closed.

To undo: `cp ~/.zprofile.bak-gtc410 ~/.zprofile`, open a new terminal
(node --version then prints v20.20.2), and in this folder run
`rm -rf node_modules && npm ci && npm run db:generate`. node@22 can stay
installed beside node@20, or be removed with `brew uninstall node@22`.
