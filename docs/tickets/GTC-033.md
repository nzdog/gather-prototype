# GTC-033 — Plan/Generate: Guided Builder UI — checkbox list and larger modal

**Type:** UX
**Severity:** P2

## The Person
A host stepping through the Guided Plan Builder. They're on the Mains level, looking at pill-shaped buttons. They want to pick Traditional roast AND NZ summer BBQ — a combined approach. But the UI implies single selection.

## The Fix
1. Replace pill buttons with checkbox list at all levels (L1, L2, L3)
2. Increase modal size to near-full viewport (~90vw × 90vh) for guided mode

## Evidence (Executor-Completed)

### What was built
Replaced pill/chip buttons with a full-width checkbox list at all option levels in the Guided Plan Builder. Each option is now a `<label>` wrapping a checkbox input with comfortable tap targets, highlighted row on selection, and bold text for selected items. The option list scrolls (`max-h-[50vh] overflow-y-auto`) if content overflows.

Increased the guided-mode modal from `max-w-2xl` to `max-w-[90vw] w-[90vw] h-[90vh]`, giving a near-full-viewport experience. Non-guided views (choice, quick) remain at `max-w-lg`.

### Files changed
- `src/components/plan/GuidedPlanBuilder.tsx` — pill buttons → checkbox list with highlighted rows
- `src/components/plan/HostDescriptionModal.tsx` — modal sizing: `max-w-[90vw] w-[90vw] h-[90vh]` for guided mode
