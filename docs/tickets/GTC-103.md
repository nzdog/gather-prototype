**Status:** Complete | **Branch:** feat/moment-one-redesign | **Commit:** bafd00d

---

### What was found

- **Person creation pattern:** `src/app/api/events/[id]/people/route.ts` uses a find-by-email-or-create pattern (`prisma.person.findUnique({ where: { email } })` → `prisma.person.create`). Reused this exact pattern in the households endpoint.
- **findOrCreate:** No standalone utility — the pattern is inline in each route. Replicated the same inline approach.
- **Phone validation:** `src/lib/phone.ts` exports `normalizePhoneNumber()` (NZ E.164) and `isInternationalNumber()`. Both reused in the new component and API endpoint.
- **Email validation:** No shared utility — uses regex inline. Replicated in both component and API.
- **Household model:** Already existed from [[GTC-101]] (`Household` with `childCount`, `members: PersonEvent[]`). `HouseholdRole` enum (`PRIMARY_CONTACT`, `PARTNER`, `GUEST`) was already in the schema.
- **Existing households route:** A basic POST existed (created empty household with childCount only). Rewrote to handle full household creation with members.

### What was changed

**New files:**
- `src/components/plan/Moment1InputForm.tsx` — Full "Who's coming?" input form with:
  - MomentArc at top (currentMoment={1})
  - Assistant line with event name
  - Primary contact fields (Name required, Email/Phone optional with "Skip for now →")
  - Add Partner sub-form (blue left border, max 1)
  - Add Children number input (1–20, stored as childCount)
  - Add Guest sub-forms (blue left border, multiple allowed)
  - "+ Add another person" button (saves household, resets form)
  - Progress counter ("X people added.")
  - "Done adding people →" button (secondary style, always visible)

**Modified files:**
- `src/app/api/events/[id]/households/route.ts` — Rewrote POST handler to accept full household payload (primaryContact, partner, childCount, guests), create Person records (find-or-create by email), create PersonEvent records with householdRole, and return complete household with members
- `src/app/plan/[eventId]/page.tsx` — Added Moment1InputForm import, `showMoment1` state, wired opening screen → Moment 1 → plan page transition
- `package.json` — Added `test:moment1-input` script
