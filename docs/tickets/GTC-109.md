# [[GTC-109]] — Kate can't remove a household she added by mistake — CLOSED

**Status:** Complete | **Branch:** feat/moment-one-redesign | **Commit:** 8bb9611

### What was found

- The `HouseholdCardList` component only had an "Edit" action on each card — no way to remove a household once added.
- The API route `src/app/api/events/[id]/households/[householdId]/route.ts` only had a PUT handler — no DELETE endpoint existed.
- Prisma schema: PersonEvent → Household relation has **no** `onDelete: Cascade`, so PersonEvent records must be explicitly deleted before the Household can be removed.
- Person records are shared across events and must not be deleted.

### What was changed

**`src/app/api/events/[id]/households/[householdId]/route.ts`**
- Added `DELETE` handler alongside existing PUT
- Verifies auth with `requireEventRole(eventId, ['HOST', 'COHOST'])`
- Validates household exists and belongs to the event
- Deletes all PersonEvent records with matching `householdId` first
- Then deletes the Household record
- Returns `{ success: true }`
- Person records are preserved

**`src/components/plan/HouseholdCardList.tsx`**
- Added `onDelete` and `editingHouseholdId` props to component
- Added "Del" link (text-red-400 hover:text-red-600 text-sm) next to "Edit" on each card
- "Del" is hidden when the card's household is currently being edited
- Clicking "Del" transforms the card inline to show "Remove [name]?" with "Remove" and "Keep" buttons — no modal, no browser confirm
- "Remove" triggers the delete; "Keep" returns to normal state
- Error handling: on DELETE failure, shows "Couldn't remove — try again." inline above card content, auto-clears after 5 seconds or on card interaction

**`src/app/plan/[eventId]/page.tsx`**
- Added `handleDeleteHousehold` async handler that calls DELETE endpoint and removes household from state on success
- Passed `onDelete={handleDeleteHousehold}` and `editingHouseholdId={editingHousehold?.id}` to both HouseholdCardList instances (mobile + desktop)

### Known limitations

- No undo after deletion — once confirmed and deleted, the household is gone from the database.

### Assertions met

1. Each household card shows a "Del" link next to "Edit" — **pass**
2. Clicking "Del" transforms the card to show "Remove [name]?" with "Remove" and "Keep" — **pass**
3. Clicking "Keep" returns the card to its normal state — **pass**
4. Clicking "Remove" deletes via DELETE endpoint and removes the card — **pass**
5. Progress counter updates after deletion (derives from households array) — **pass**
