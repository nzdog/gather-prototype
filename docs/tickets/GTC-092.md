# GTC-092 — ConflictCard: "Go fix it" navigation and "Ignore" button — CLOSED

**Status:** Complete | **Branch:** master | **Commit:** [pending]

### What was found

- ConflictCard is rendered via ConflictList in two places on the plan page (lines ~1858 and ~2074).
- ConflictList manages its own API handlers for resolve, dismiss, delegate, acknowledge, and resolve-with-AI.
- The existing "Dismiss" button called `POST /api/events/{eventId}/conflicts/{conflictId}/dismiss`. "Ignore" reuses this endpoint.
- `handleExpandSection` in the plan page navigates by setting a URL query param `?expand=<sectionId>`. Section IDs include `items`, `people`, `teams`, `planstatus`.
- The `onDismiss` prop was removed from ConflictCard since "Ignore" fully replaces "Dismiss". ConflictList's `handleDismiss` is reused as the `onIgnore` handler.

### What was changed

**`src/components/plan/ConflictCard.tsx`:**
- Removed `onDismiss` prop (replaced by `onIgnore`).
- Added `onIgnore: (conflictId: string) => void` prop.
- Added `onGoFixIt: (conflictId: string, conflictType: ConflictType) => void` prop.
- Replaced "Dismiss" button with "Ignore" button (same style, new label).
- Added "Go fix it →" button with secondary style (`bg-gray-200 text-gray-700`).
- Removed the conditional that only showed "Dismiss" for non-critical conflicts — "Ignore" now appears on all cards. For CRITICAL conflicts, "Acknowledge" also appears alongside it.
- Button layout: `[Resolve with AI] [Mark Resolved] [Go fix it →] [Ignore] [Acknowledge/Delegate]`.
- Added `flex-wrap` to the button row to handle overflow gracefully.

**`src/components/plan/ConflictList.tsx`:**
- Added `onGoFixIt?: (conflictId: string, conflictType: ConflictType) => void` prop.
- Removed `onDismiss` from ConflictCard render calls.
- Added `onIgnore={handleDismiss}` (reuses existing dismiss API handler).
- Added `onGoFixIt={onGoFixIt ?? (() => {})}` to all three ConflictCard render sites.
- Added `ConflictType` import from `@prisma/client`.

**`src/app/plan/[eventId]/page.tsx`:**

- Added `handleGoFixIt` handler that calls `handleExpandSection` with the mapped section.
- Passed `onGoFixIt={handleGoFixIt}` to both ConflictList instances.

**`src/app/dev/conflicts/page.tsx`:**
- Added `ConflictType` to imports.

- Added `onIgnore` and `onGoFixIt` props to ConflictCard render.

### Known limitations

- "Go fix it →" navigates to the section modal but does not scroll to or highlight the specific affected item/team.
- The conflict panel is not explicitly closed before navigation — `handleExpandSection` sets a new `?expand=` param which replaces the current view.
